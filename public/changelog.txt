RoverSim changelog

v0.5 (2026-10-06)
- 14 levels. Levels 1 to 7 are redone so that, together, they teach every
  piece of C++ the later levels use: variables, ++, for, while, if /
  else if, bool, your own functions, and functions that give back a value.
- Levels 8 to 14 are new and get harder as they go, up to ones meant to
  make people who already code think.
- Level 1's starting code points out each part of a program: #include,
  setup(), { }, ( ), ;, and comments.
- A Commands list next to Hint shows everything you can write.
- Levels moved around, so code and checkmarks saved for levels that changed
  are gone. Stairs forever (now level 2) and the sandbox (now 15) kept
  yours.
- If the rover skips a circle, it now says which circle it still needs.

v0.4 (2026-10-05)
- Levels 1 to 7 plus the sandbox.
- Some maps change every time you press Run. A level only counts as done
  when your code works on every version of the map.
- Your code and finished levels are saved in this browser.
- The goal only counts if the rover stops on the X, like the real rover.
- The sketched simulator, Run / Step / Stop / Reset, and the speed slider.
- The C++ interpreter and all the error messages, tested first.
